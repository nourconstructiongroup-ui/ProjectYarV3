# پروژه‌یار نسخه ۲ — نمونه آزمایشی

این پروژه یک برنامه اندرویدی WebView با داده‌های محلی است.

## ساخت APK با GitHub
1. محتویات پوشه را در ریشه یک مخزن GitHub آپلود کنید.
2. به Actions > Build Android APK بروید و Run workflow را بزنید (یا در شاخه main یک push انجام دهید).
3. پس از موفقیت، از بخش Artifacts فایل projectyar-v2-apk را دریافت کنید.

## محدودیت‌ها
- اطلاعات فقط در حافظه داخلی برنامه روی همان گوشی ذخیره می‌شوند. حذف برنامه ممکن است داده‌ها را پاک کند.
- چندکاربره آنلاین، ارسال پیامک خودکار، اعلان زمان‌بندی‌شده چک‌ها و همگام‌سازی سرور هنوز پیاده‌سازی نشده‌اند.
- تاریخ‌های ورودی فعلاً میلادی هستند.
- برای استفاده مالی واقعی، قبل از هر چیز باید پشتیبان‌گیری، کنترل دسترسی و صحت گردش حساب توسعه یابد.

## تغییرات نسخه ۲.۱
- بخش پیمانکاران با ثبت و ویرایش مشخصات، پروژه و تخصص‌ها اضافه شد.
- دسته‌های فعالیت و زیرمجموعه‌های پیش‌فرض قابل ویرایش/افزودن/حذف هستند؛ برای هر پیمانکار می‌توان چند زیرتخصص انتخاب کرد.
- صفحه اصلی دارای کاشی‌های دسترسی سریع و آیکون اختصاصی برنامه است.
- دکمه بازگشت اندروید ابتدا فرم باز را می‌بندد یا به صفحه اصلی برمی‌گردد.
- Workflow برای Gradle 8.9 تنظیم شده و مرحله اضافی setup-android حذف شده است.

**نکته:** این نسخه هنوز نسخه آزمایشی آفلاین است. امکانات پیشنهادی دیگر (چندکاربره آنلاین، صورت‌وضعیت تفصیلی و PDF، ارسال خودکار پیامک، یادآوری سیستم‌عامل و پشتیبان‌گیری) در این بسته پیاده‌سازی نشده‌اند. قبل از نصب جدید از داده‌های فعلی خود نسخه پشتیبان بگیرید؛ پاک کردن اپ داده‌های محلی را حذف می‌کند.
